Was beim Aufruf passiert

Diese Seite setzt keine Cookies, nutzt keine Analyse- oder Tracking-Dienste und hat keine Benutzerkonten.

Hosting und Server-Logs. Die Seite wird über Cloudflare (Cloudflare, Inc., USA) ausgeliefert, das Anfragen an den Server weiterleitet. Dabei verarbeiten Cloudflare und der Server technisch notwendige Daten (IP-Adresse, Zeitpunkt, aufgerufene Adresse, Browserkennung). Der Server speichert diese Zugriffsprotokolle zur Abwehr von Angriffen und löscht sie nach kurzer Zeit. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem sicheren Betrieb). Cloudflare ist unter dem EU-US Data Privacy Framework zertifiziert.

Karte. Beim Öffnen der Karte (map.html) lädt Ihr Browser die Kartenbibliothek Leaflet von unpkg.com und Kartenkacheln von tile.openstreetmap.org (OpenStreetMap Foundation). Diese Anbieter erhalten dabei Ihre IP-Adresse. Die übrigen Seiten laden nichts von Dritten.

Ihre Rechte

Sie haben das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und Widerspruch sowie das Recht auf Beschwerde bei einer Aufsichtsbehörde, in Berlin bei der Berliner Beauftragten für Datenschutz und Informationsfreiheit.

Die Daten der Seite selbst

Die ausgewerteten Daten stammen aus dem öffentlichen GBFS-Feed von nextbike. Fahrrad-IDs werden nie gespeichert; es gibt keine Daten über einzelne Fahrten oder Personen.

Privacy

No cookies, no analytics, no tracking, no accounts. The site is served through Cloudflare; Cloudflare and the server process technically necessary request data (IP address, time, URL, user agent), and the server keeps short-lived access logs for security. Opening the map loads Leaflet from unpkg.com and map tiles from tile.openstreetmap.org, which receive your IP address. Bike ids from the feed are never stored, so there is no data about individual trips or people.
